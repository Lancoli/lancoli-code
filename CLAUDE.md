# Lancoli Code — règles de l'app

La vitrine technique : chaque projet du portfolio, à quoi il sert, comment il est fait, et le journal (voir [README.md](README.md)).
Règles communes : [../CLAUDE.md](../CLAUDE.md).

## Règles propres

- **Chaque carte de projet** dit le problème résolu, l'impact pour l'utilisateur et les choix techniques, sans jargon
  ([../docs/VISION.md](../docs/VISION.md), « Application aux cartes de projets »).
- **Ne rien inventer** : un chiffre, une techno ou un résultat cité vient du code du projet ou de David.
- Le journal se tient depuis git (skill `devlog`), pas à la main.

## Vérifier

`node tools/jalons.mjs LancoliCode` · `lancer liens LancoliCode` (depuis la racine).
